## Features

- Renamed the official npm CLI package to `openctrlc`, matching the command users run. Install it with `npm install -g openctrlc`; the former `openctrlc-ai` package remains available as a migration alias.
- Added the npm installation option to the website download page, README files, and English, Simplified Chinese, Japanese, and Korean getting-started guides.

## Bug Fixes

- Limited the Desktop settings database list to databases belonging to OpenCtrlC and the Desktop app.
