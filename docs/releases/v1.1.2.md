## Features

- Restore the Desktop's open projects, session tabs, and selected session when a browser connects to remote access.
- Keep approved browsers authorized across Desktop restarts and allow configurable browser limits, defaulting to 10.
- Show session storage usage and improve remote-session recovery after reconnects.
- Add an optional WebRTC direct path to reduce Relay traffic when the Relay advertises a working ICE configuration. Existing HTTPS/WebSocket Relay transport remains the fallback.

## Bug Fixes

- Fixed remote pages that opened without the Desktop's projects or sessions and improved recovery after the Desktop restarts.
- Fixed remote pages appearing blank when forwarded responses were compressed or UI assets were resolved from a different working directory.
- Improved session switching and initial loading on slower networks by loading large history, media, and model catalogs only when needed.
- Fixed session history pagination and catch-up so reconnects do not miss older or newly arrived messages.
- Fixed live messages and parts being overwritten when session history loads at the same time.
- Fixed mobile-access controls being clipped or difficult to use in narrow layouts.
