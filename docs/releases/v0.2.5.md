## Features

- Unified the OpenCtrlC brand mark across the website, 404 page, and shared application UI.
- Added a clear, optional way to support the independent OpenCtrlC project from the website.
- Improved the download experience with platform guidance that does not misidentify Apple Silicon Macs.

## Bug Fixes

- Fixed the website header and shared wordmark still rendering parts of the upstream OpenCode branding.
- Fixed macOS download guidance being tied to an unreliable browser CPU-architecture guess.
- Fixed a Windows-only CI failure caused by source-text assertions assuming Unix line endings.
