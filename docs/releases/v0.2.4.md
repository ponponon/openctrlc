## Features

- Improved session reliability with permission-wait recovery, stall diagnostics, and
  clearer session navigation and context visibility.
- Improved provider, ACP, CLI, and Desktop compatibility across local and remote
  development workflows.
- Added a stable public download path backed by Cloudflare R2, with GitHub Release
  fallback when the accelerated mirror is unavailable.
- Expanded the OpenCtrlC website with localized marketing content, clearer product
  positioning, and a platform-aware download experience.
- Added release-time validation for Desktop icon sizes, transparent corner insets,
  and packaged resources across supported targets.

## Bug Fixes

- Fixed sessions that could remain stuck while waiting for permissions or recovering
  from missed request events.
- Fixed Windows and Linux test/runtime compatibility issues, including cold-start,
  temporary Git repository, and protocol-mock timing problems.
- Fixed dynamic download failures, missing ARM64 mappings, and the Intel macOS CLI
  download dead link.
- Fixed localized website routes that could display the English marketing page after
  changing language.
- Removed stale upstream product branding and unsupported hosted-service claims from
  public website and documentation surfaces.
