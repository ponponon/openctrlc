## Features

- Added an expanded session chart for comparing assistant messages by average token rate, token counts, cache usage, cost, and elapsed time.
- Added provider and model filters, recent-message ranges, summary statistics, and average/median/peak markers to the session chart.
- Added interactive chart details with keyboard and touch support, plus a shortcut to open the matching message in the raw message list.

## Bug Fixes

- Unified the average token-rate calculation across the chart and message list, including time spent waiting for the first token and running tools.
- Fixed chart labels, dynamic translations, and layout clipping in the analysis view.
- Stabilized cross-platform manifest checks by sorting scanned entries before comparing them.
