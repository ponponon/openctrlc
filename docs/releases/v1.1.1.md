## Features

- Restore the Desktop's open projects, session tabs, and active session when a newly approved browser connects. The workspace index is held in relay memory only and excludes prompts, drafts, and message bodies.
- Recover missed session messages incrementally after disconnects, with paginated history replay for long conversations.

## Bug Fixes

- Fixed the remote web page appearing blank when the relay forwarded compressed responses.
- Fixed the mobile access approval action wrapping and becoming difficult to use in a narrow dialog.
- Fixed Cloudflare models remaining visible after Cloudflare access was disabled.
- Improved session catch-up after reconnects to avoid missing messages or reloading the full history unnecessarily.
