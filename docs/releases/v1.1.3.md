## Features

- Added change-only remote workspace refresh support for Relay servers that expose workspace snapshots.

## Bug Fixes

- Fixed remote browsers showing only a stale local project or an empty list when an older Relay supplied the full desktop workspace through its legacy bootstrap key.
- Kept session content readable when the Markdown highlighting worker cannot start, and preserved the underlying session error instead of reporting it as a network timeout.
