## Features

- Added one-click mobile access from Desktop. Scan a QR code to open the current workspace over HTTPS; each new browser requires explicit Desktop approval, and approved browsers can be revoked individually.
- Added short-disconnect recovery for mobile access. The Desktop reconnects to the existing Relay session and restores approved browsers without requiring a new QR code during the recovery window.
- Added release-note previews to Desktop updates, with separate feature and bug-fix sections before and after upgrading.
- Added optional cost and token detail columns to the session context message list.

## Bug Fixes

- Improved mobile pairing status updates and browser authorization controls.
- Prevented long dialogs and mobile-access controls from being clipped in smaller or dynamically sized windows.
- Improved session-time, database-list, and message-cost displays.
