## Features

- Added Windows system tray support. Closing the window keeps OpenCtrlC running in the tray, where you can reopen the app, create a session, open a project or settings, export logs, check for updates, or quit.
- New directories automatically accept permission requests by default. You can turn this off with the directory permission control.
- Added removal controls for queued follow-up messages.
- Added activity details and elapsed time to the session context message list, and a completion status to session tabs.
- Added output counts while browsing earlier messages, and improved search navigation with centered, highlighted matches in tool input and output.
- Added a Settings shortcut for locating the local session database.
- Limited application language choices to English, Simplified Chinese, Japanese, and Korean.
- Hid Cloudflare AI Gateway models from the model picker by default, with a setting to show them when needed.

## Bug Fixes

- Fixed missing session context on first open and duplicate optimistic messages.
- Preserved each session's reading position when switching tabs, and stopped new streamed output from pulling readers away from earlier messages.
- Fixed search results that could be positioned incorrectly or fail to reveal matching tool content.
- Fixed development-mode Desktop restarts that could leave the local service stopped.
- Improved session and MCP recovery so cancellation or an isolated MCP startup failure does not disrupt other session state.
