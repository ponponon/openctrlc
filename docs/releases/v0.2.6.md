## Features

- Added a clear queue-or-steer setting for follow-up messages during an active session.
- Kept queued follow-ups durable and ordered so a new message does not replace the task currently running.

## Performance and Reliability

- Improved recovery so active sessions are not falsely marked as interrupted during polling or reconnects.
- Preserved queued and steering inputs across interruptions and process restarts where durable state is available.
- Added explicit handling for model turns that end with reasoning or empty content but no user-visible answer.

## UI Improvements

- Added clearer activity labels for tools, reasoning, responses, compaction, retries, and incomplete work.
- Show an em dash instead of zero tokens while an assistant message is still incomplete and has no confirmed usage.

## Bug Fixes

- Fixed sessions that could remain in progress after a runner, permission wait, or tool execution disappeared during restart.
- Fixed empty assistant turns being reported as successful without any visible response.
- Fixed release workflow contract coverage after adding the download synchronization job.
