---
title: 分享
description: 配置 OpenCtrlC 的可选会话分享功能。
---

OpenCtrlC 可以接入兼容的分享服务，但 OpenCtrlC 公共官网目前不提供托管的分享后端。因此，分享功能默认应保持关闭；只有在你自己配置并审核过目标服务后，才建议开启。

:::caution
分享的会话可能包含源代码、提示词、命令输出和模型回复。请把每个分享链接都视为“拥有链接的人都可以访问”。
:::

## 关闭分享

对于普通本地开发，以及尚未批准分享服务的项目，请使用：

```json title="openctrlc.json"
{
  "$schema": "https://openctrlc.pages.dev/config.json",
  "share": "disabled"
}
```

也可以在进程环境中设置 `OPENCTRLC_DISABLE_SHARE=1`，关闭当前进程的分享功能。

## 自管理分享服务

如果你的组织运行了兼容的分享后端，请按照对应部署文档配置它的 URL。后端需要自行负责身份认证、数据保留、删除和访问控制。开启 `manual` 或 `auto` 之前，请先审查后端实现。

## 分享前检查

- 删除 API key、Token、密码和不应公开的源代码。
- 完整检查会话内容和工具输出。
- 如果确实需要分享，优先使用 `manual`，由用户明确触发。
- 只有在项目中的每段会话都允许发送到目标服务时，才使用 `auto`。
- 协作完成后删除已分享的数据。
