[**OpenCtrlC**](/) คือเอเจนต์การเข้ารหัส AI แบบโอเพ่นซอร์ส มีให้บริการในรูปแบบอินเทอร์เฟซบน terminal แอปเดสก์ท็อป หรือส่วนขยาย IDE

![OpenCtrlC ในเทอร์มินัล](../../../assets/lander/terminal-preview.svg)

มาเริ่มกันเลย

---

#### ข้อกำหนดเบื้องต้น

หากต้องการใช้ OpenCtrlC ใน terminal คุณจะต้องมี:

1. terminal อีมูเลเตอร์ที่ทันสมัยเช่น:
   - [WezTerm](https://wezterm.org) ข้ามแพลตฟอร์ม
   - [Alacritty](https://alacritty.org) ข้ามแพลตฟอร์ม
   - [Ghostty](https://ghostty.org), Linux และ macOS
   - [Kitty](https://sw.kovidgoyal.net/kitty/), Linux และ macOS

2. API Key สำหรับผู้ให้บริการ LLM ที่คุณต้องการใช้

---

## ติดตั้ง

The installer script detects the current operating system and CPU architecture.

```bash
curl -fsSL https://raw.githubusercontent.com/ponponon/openctrlc/dev/install | bash
```

For platform-specific packages, use the [OpenCtrlC download page](https://openctrlc.pages.dev/download/) or [GitHub Releases](https://github.com/ponponon/openctrlc/releases). Stable downloads use the project's Cloudflare R2 mirror when available and automatically fall back to GitHub.

---

## กำหนดค่า

OpenCtrlC is a client application. Configure an LLM provider that you control; OpenCtrlC does not provide a hosted model service.

1. Run `/connect` in the TUI and select a supported provider. See [Providers](/docs/providers).

   ```txt
   /connect
   ```

2. Follow the provider's setup guide and paste its API key when prompted.

## เริ่มต้น

เมื่อคุณได้กำหนดค่าผู้ให้บริการแล้ว คุณสามารถนำทางไปยังโปรเจ็กต์นั้นได้
คุณอยากทำงานต่อ

```bash
cd /path/to/project
```

และเรียกใช้ OpenCtrlC

```bash
openctrlc
```

จากนั้น เริ่มต้น OpenCtrlC สำหรับโปรเจ็กต์โดยการรันคำสั่งต่อไปนี้

```bash frame="none"
/init
```

นี่จะได้รับ OpenCtrlC เพื่อวิเคราะห์โครงการของคุณและสร้างไฟล์ `AGENTS.md`
รากของโครงการ

:::tip
คุณควรคอมมิตไฟล์ `AGENTS.md` ของโปรเจ็กต์ของคุณไปที่ Git
:::

ซึ่งจะช่วยให้ OpenCtrlC เข้าใจโครงสร้างโปรเจ็กต์และรูปแบบการเขียนโค้ด
ใช้แล้ว.

## การใช้งาน

ตอนนี้คุณพร้อมที่จะใช้ OpenCtrlC เพื่อทำงานในโครงการของคุณแล้ว อย่าลังเลที่จะถามมัน
อะไรก็ตาม!

หากคุณยังใหม่ต่อการใช้เอเจนต์การเข้ารหัส AI ต่อไปนี้คือตัวอย่างบางส่วนที่อาจเป็นไปได้
ช่วย.

---

### ถามคำถาม

คุณสามารถขอให้ OpenCtrlC อธิบาย codebase ให้คุณได้

:::tip
ใช้ปุ่ม `@` เพื่อค้นหาไฟล์ในโครงการอย่างคลุมเครือ
:::

```txt frame="none" "@src/api/index.ts"
How is authentication handled in @src/api/index.ts
```

สิ่งนี้มีประโยชน์หากมีส่วนหนึ่งของโค้ดเบสที่คุณไม่ได้ดำเนินการ

---

### เพิ่มคุณสมบัติ

คุณสามารถขอให้ OpenCtrlC เพิ่มคุณสมบัติใหม่ให้กับโครงการของคุณได้ แม้ว่าเราจะแนะนำให้ขอให้สร้างแผนก่อนก็ตาม

1. **สร้างแผน**

   OpenCtrlC มีโหมด _Plan_ ที่ปิดการใช้งานความสามารถในการเปลี่ยนแปลงและ
   แนะนำ _how_ ว่าจะใช้งานฟีเจอร์นี้แทน

   เปลี่ยนไปใช้ปุ่ม **Tab** คุณจะเห็นตัวบ่งชี้นี้ที่มุมขวาล่าง

   ```bash frame="none" title="Switch to Plan mode"
   <TAB>
   ```

   ตอนนี้เรามาอธิบายสิ่งที่เราต้องการให้ทำ

   ```txt frame="none"
   When a user deletes a note, we'd like to flag it as deleted in the database.
   Then create a screen that shows all the recently deleted notes.
   From this screen, the user can undelete a note or permanently delete it.
   ```

   คุณต้องการให้รายละเอียด OpenCtrlC เพียงพอเพื่อทำความเข้าใจสิ่งที่คุณต้องการ มันช่วยได้
   เพื่อพูดคุยเหมือนคุณกำลังพูดคุยกับนักพัฒนารุ่นน้องในทีมของคุณ

   :::tip
   ให้บริบทและตัวอย่างมากมายแก่ OpenCtrlC เพื่อช่วยให้เข้าใจสิ่งที่คุณ
   ต้องการ.
   :::

2. **ทบทวนแผน**

   เมื่อมีแผนแล้ว คุณสามารถให้ข้อเสนอแนะหรือเพิ่มรายละเอียดเพิ่มเติมได้

   ```txt frame="none"
   We'd like to design this new screen using a design I've used before.
   [Image #1] Take a look at this image and use it as a reference.
   ```

   :::tip
   ลากและวางรูปภาพลงใน terminal เพื่อเพิ่มลงในพรอมต์
   :::

   OpenCtrlC สามารถสแกนรูปภาพที่คุณให้มาและเพิ่มลงในข้อความแจ้งได้ คุณสามารถ
   ทำได้โดยลากและวางรูปภาพลงใน terminal

3. **สร้างฟีเจอร์**

   เมื่อคุณรู้สึกพอใจกับแผนแล้ว ให้เปลี่ยนกลับเป็น _Build mode_ ภายใน
   กดปุ่ม **Tab** อีกครั้ง

   ```bash frame="none"
   <TAB>
   ```

   และขอให้ทำการเปลี่ยนแปลง

   ```bash frame="none"
   Sounds good! Go ahead and make the changes.
   ```

### ทำการเปลี่ยนแปลง

หากต้องการการเปลี่ยนแปลงที่ตรงไปตรงมามากขึ้น คุณสามารถขอให้ OpenCtrlC สร้างมันโดยตรงได้
โดยไม่ต้องทบทวนแผนก่อน

```txt frame="none" "@src/settings.ts" "@src/notes.ts"
We need to add authentication to the /settings route. Take a look at how this is
handled in the /notes route in @src/notes.ts and implement
the same logic in @src/settings.ts
```

คุณต้องการให้แน่ใจว่าคุณให้รายละเอียดในปริมาณที่เหมาะสมเพื่อให้ OpenCtrlC ดำเนินการได้ถูกต้อง
การเปลี่ยนแปลง

---

### เลิกทำการเปลี่ยนแปลง

สมมติว่าคุณขอให้ OpenCtrlC ทำการเปลี่ยนแปลงบางอย่าง

```txt frame="none" "@src/api/index.ts"
Can you refactor the function in @src/api/index.ts?
```

แต่คุณก็รู้ว่ามันไม่ใช่สิ่งที่คุณต้องการ คุณ **สามารถยกเลิก** การเปลี่ยนแปลงได้
โดยใช้คำสั่ง `/undo`

```bash frame="none"
/undo
```

OpenCtrlC จะคืนค่าการเปลี่ยนแปลงที่คุณทำและแสดงข้อความต้นฉบับของคุณ
อีกครั้ง.

```txt frame="none" "@src/api/index.ts"
Can you refactor the function in @src/api/index.ts?
```

จากที่นี่ คุณสามารถปรับแต่งข้อความแจ้งและขอให้ OpenCtrlC ลองอีกครั้ง

:::tip
คุณสามารถเรียกใช้ `/undo` ได้หลายครั้งเพื่อเลิกทำการเปลี่ยนแปลงหลายรายการ
:::

หรือคุณสามารถ **สามารถทำซ้ำ** การเปลี่ยนแปลงโดยใช้คำสั่ง `/redo`

```bash frame="none"
/redo
```
