[**OpenCtrlC**](/) هو وكيل ترميز بالذكاء الاصطناعي مفتوح المصدر. يتوفر كواجهة terminal، وتطبيق لسطح المكتب، أو إضافة لبيئة تطوير متكاملة (IDE).

![واجهة OpenCtrlC في الطرفية](../../../assets/lander/terminal-preview.svg)

لنبدأ.

---

#### المتطلبات

لاستخدام OpenCtrlC في terminal، ستحتاج إلى:

1. محاكي terminal حديث مثل:
   - [WezTerm](https://wezterm.org) متعدد المنصات
   - [Alacritty](https://alacritty.org) متعدد المنصات
   - [Ghostty](https://ghostty.org) على Linux وmacOS
   - [Kitty](https://sw.kovidgoyal.net/kitty/) على Linux وmacOS

2. مفاتيح API لمزوّدي نماذج اللغة (LLM) الذين تريد استخدامهم.

---

## التثبيت

The installer script detects the current operating system and CPU architecture.

```bash
curl -fsSL https://raw.githubusercontent.com/ponponon/openctrlc/dev/install | bash
```

For platform-specific packages, use the [OpenCtrlC download page](https://openctrlc.pages.dev/download/) or [GitHub Releases](https://github.com/ponponon/openctrlc/releases). Stable downloads use the project's Cloudflare R2 mirror when available and automatically fall back to GitHub.

## الإعداد

OpenCtrlC is a client application. Configure an LLM provider that you control; OpenCtrlC does not provide a hosted model service.

1. Run `/connect` in the TUI and select a supported provider. See [Providers](/docs/providers).

   ```txt
   /connect
   ```

2. Follow the provider's setup guide and paste its API key when prompted.

## التهيئة

بعد أن قمت بإعداد مزوّد، يمكنك الانتقال إلى المشروع الذي تريد العمل عليه.

```bash
cd /path/to/project
```

ثم شغّل OpenCtrlC.

```bash
openctrlc
```

بعد ذلك، هيّئ OpenCtrlC للمشروع عبر تشغيل الأمر التالي.

```bash frame="none"
/init
```

سيجعل هذا OpenCtrlC يحلل مشروعك ويُنشئ ملف `AGENTS.md` في جذر المشروع.

:::tip
يستحسن أن تقوم بعمل commit لملف `AGENTS.md` الخاص بمشروعك إلى Git.
:::

يساعد هذا OpenCtrlC على فهم بنية المشروع وأنماط الترميز المستخدمة.

## الاستخدام

أصبحت الآن جاهزا لاستخدام OpenCtrlC للعمل على مشروعك. لا تتردد في سؤاله أي شيء!

إذا كنت جديدا على استخدام وكيل ترميز بالذكاء الاصطناعي، فإليك بعض الأمثلة التي قد تساعد.

---

### اطرح أسئلة

يمكنك أن تطلب من OpenCtrlC شرح قاعدة الشيفرة لك.

:::tip
استخدم المفتاح `@` للبحث التقريبي عن الملفات داخل المشروع.
:::

```txt frame="none" "@src/api/index.ts"
How is authentication handled in @src/api/index.ts
```

يفيد هذا عندما تكون هناك أجزاء من قاعدة الشيفرة لم تعمل عليها.

---

### أضف ميزات

يمكنك أن تطلب من OpenCtrlC إضافة ميزات جديدة إلى مشروعك، لكننا نوصي أولا بطلب إنشاء خطة.

1. **أنشئ خطة**

   لدى OpenCtrlC _وضع Plan_ يعطل قدرته على إجراء التغييرات، ويقترح بدلا من ذلك _كيف_ سينفّذ الميزة.

   انتقل إليه باستخدام مفتاح **Tab**. سترى مؤشرا لذلك في الزاوية السفلية اليمنى.

   ```bash frame="none" title="التبديل إلى وضع Plan"
   <TAB>
   ```

   الآن لنصف ما نريده أن يفعله.

   ```txt frame="none"
   When a user deletes a note, we'd like to flag it as deleted in the database.
   Then create a screen that shows all the recently deleted notes.
   From this screen, the user can undelete a note or permanently delete it.
   ```

   احرص على تزويد OpenCtrlC بتفاصيل كافية ليفهم ما تريد. يساعد أن تتحدث إليه كما لو كنت تتحدث إلى مطور مبتدئ ضمن فريقك.

   :::tip
   أعطِ OpenCtrlC سياقا وأمثلة كافية لمساعدته على فهم ما تريد.
   :::

2. **حسّن الخطة**

   بعد أن يقدم لك خطة، يمكنك إعطاؤه ملاحظات أو إضافة تفاصيل أكثر.

   ```txt frame="none"
   We'd like to design this new screen using a design I've used before.
   [Image #1] Take a look at this image and use it as a reference.
   ```

   :::tip
   اسحب الصور وأفلِتها داخل terminal لإضافتها إلى الطلب.
   :::

   يستطيع OpenCtrlC فحص أي صور تزوده بها وإضافتها إلى الطلب. يمكنك فعل ذلك عبر سحب الصورة وإفلاتها داخل terminal.

3. **ابنِ الميزة**

   عندما تشعر بالارتياح للخطة، عد إلى _وضع Build_ بالضغط على مفتاح **Tab** مرة أخرى.

   ```bash frame="none"
   <TAB>
   ```

   ثم اطلب منه تنفيذ التغييرات.

   ```bash frame="none"
   Sounds good! Go ahead and make the changes.
   ```

---

### نفّذ تغييرات

للتغييرات الأبسط، يمكنك أن تطلب من OpenCtrlC تنفيذها مباشرة دون الحاجة لمراجعة خطة أولا.

```txt frame="none" "@src/settings.ts" "@src/notes.ts"
We need to add authentication to the /settings route. Take a look at how this is
handled in the /notes route in @src/notes.ts and implement
the same logic in @src/settings.ts
```

تأكد من تقديم قدر مناسب من التفاصيل لكي يجري OpenCtrlC التغييرات الصحيحة.

---

### تراجع عن التغييرات

لنفترض أنك طلبت من OpenCtrlC إجراء بعض التغييرات.

```txt frame="none" "@src/api/index.ts"
Can you refactor the function in @src/api/index.ts?
```

لكن تتضح لك لاحقا أنها ليست ما تريده. يمكنك **التراجع** عن التغييرات باستخدام الأمر `/undo`.

```bash frame="none"
/undo
```

سيقوم OpenCtrlC الآن بعكس التغييرات التي أُجريت ويعرض رسالتك الأصلية مجددا.

```txt frame="none" "@src/api/index.ts"
Can you refactor the function in @src/api/index.ts?
```

من هنا يمكنك تعديل الطلب وطلب المحاولة مرة أخرى.

:::tip
يمكنك تشغيل `/undo` عدة مرات للتراجع عن عدة تغييرات.
:::

أو يمكنك **إعادة تنفيذ** التغييرات باستخدام الأمر `/redo`.

```bash frame="none"
/redo
```
