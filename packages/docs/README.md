# Legacy documentation workspace

This directory is retained only as historical source material from an earlier
documentation experiment. It is not part of the deployed OpenCtrlC website
and should not be used for new documentation.

The maintained public documentation lives in [`packages/web`](../web) and is
published at <https://openctrlc.pages.dev/docs/>. Update the Astro/Starlight
content there, then verify the English and Chinese routes with the production
build described in `packages/web/README.md`.
